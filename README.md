# Watchlist Project
A watchlist generator and organizational tool for deciding movie night films. A project for CS193 @ Purdue.
## Project Goal
The goal of this project is to create an interactive web application that helps groups of friends organize movies and decide what to watch together. Users will be able to submit movie suggestions, categorize films, and enter their interests and available free time. The application will use this information to generate movie recommendations that fit the group's preferences and schedule.

## The overall purpose of this project is to make choosing a movie easier, more organized, and more collaborative.

## MVP Scope
The initial version of the application will focus on organizing movie suggestions and generating recommendations.

## The MVP will include:
* Movie Input: Allow users to enter movie titles they are interested in watching.
* Movie Categorization: Organize movies by genre or other categories.
* User Preferences: Allow users to enter their movie interests and preferences.
* Availability: Allow users to indicate how much time they have available.
* Movie Matching: Compare movie genres, runtimes, and group preferences.
* Random Selection: Randomly select a movie from the matching options.
* Recommendation Display: Display the selected movie and its information.
